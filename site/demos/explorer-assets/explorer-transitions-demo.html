All four cinematic transitions from useGridTransitions.ts — same timing constants, same easing curves, same JS logic. No framework needed.

01 — Overlay Fade
Metadata badges show/hide

Targets every [data-overlay] element inside each card. Toggle fires once; CSS transition handles the rest.

300ms · cubic-bezier(0.76, 0, 0.24, 1)

02 — Density Reflow
Grid column cross-fade on slider

Grid fades to opacity 0 (140ms), columns update, double-rAF waits for layout commit, grid fades back in (210ms). GSAP Flip runs inside the dark window.

350ms total · fade-out 140ms + fade-in 210ms
Density 5
03 — Scroll-in Fade
Cards enter viewport with stagger

IntersectionObserver batches cards entering within a 16ms window, then staggers them at 35ms each. Cards already seen are skipped. Scroll down inside the panel.

380ms per card · 35ms stagger · threshold 0.05
Scroll to reveal
04 — Page Load Entrance
Staggered grid mount animation

On mount, each card enters with opacity + translateY stagger. Fires once, marks each card data-card-seen so the scroll observer skips already-animated cards.

320ms per card · 28ms stagger · 80ms initial delay
Page load simulation
