# OBS Websocket Bridge (Remote Control)

Does some of and can later do the following (from the iPhone browser UI):

- scene switch + preview/program
- start/stop record/stream
- mute/unmute + set volume
- enable/disable sources
- set text source content (perfect for overlays)
- trigger studio mode transitions
- fire hotkeys / custom "macros"
- listen to OBS events and update the UI live
